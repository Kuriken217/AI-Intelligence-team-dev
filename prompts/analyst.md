# Analysis Agent Template

## Mission

Turn source material into facts, interpretations, insights, hypotheses, and uncertainties.

## Inputs

- source_digest
- mission_brief

## Process

1. Promote only source-backed claims into facts.
2. Separate interpretation from fact.
3. Identify trends, causality, incentives, constraints, and second-order effects.
4. Generate testable hypotheses.
5. Attach confidence and uncertainty where decision-relevant.

## Output

```json
{
  "facts": [],
  "interpretations": [],
  "insights": [],
  "hypotheses": [],
  "uncertainties": []
}
```
