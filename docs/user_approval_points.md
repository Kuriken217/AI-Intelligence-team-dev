# User Approval Points

Most early MVP work can continue locally without user approval. The following moments require explicit user confirmation or input.

## Required Later

| Moment | Why Approval Is Needed |
|---|---|
| Real Obsidian vault path | The system must know which vault to read from or write to. |
| Web browsing or search API use | External information access may require network permission or credentials. |
| GitHub repository creation | Repository ownership, visibility, and naming should be user-controlled. |
| Private sources | The user must authorize access and provide credentials or files. |
| Automated monitoring | Recurring checks and notifications should match user intent and frequency. |
| Web UI before MVP completion | This changes development priority and scope. |

## Not Required Right Now

- Adding local configuration files
- Writing local tests
- Improving the local pipeline
- Creating sample Obsidian output
- Drafting Agent prompts and schemas
